## 用支付宝订阅 X Premium 的完整流程

WildAI 的 X 订阅流程和 ChatGPT、Claude 等产品不同。它不要求用户导出 Cookie，也不要求提交账号 Session。核心步骤是获取自己账号对应的 Stripe 订阅链接。

### 第一步：准备 X 账号

先确认以下条件：

- 你能正常登录自己的 X 账号；
- 账号可以进入 Premium 订阅页面；
- 账号已经满足 X 的基本订阅要求；
- 你使用的是电脑浏览器；
- 你准备订阅的是月付方案。

WildAI 帮助中心明确建议使用电脑端操作，手机端可能无法完整生成和复制订阅链接。

### 第二步：在 X 页面选择套餐

登录 X 后，进入 Premium 订阅页面，选择目标套餐和月付方式。点击订阅后，页面会跳转到 Stripe 结账页面。

这时不要只复制 X 的 Premium 页面地址。WildAI 要求提交的是浏览器地址栏中完整的 Stripe 链接。地址通常会很长，可能包含一串看起来不太友好的字符。不要手动删减，也不要只复制域名或页面标题。

### 第三步：复制完整 Stripe 链接

在 Stripe 页面使用电脑键盘全选地址栏内容，再复制完整链接。然后打开 WildAI 的 X Premium 订阅入口，把链接粘贴到对应输入框。

常见错误包括：

- 复制成了 X Premium 页面链接；
- 地址栏内容没有复制完整；
- 误用了年付链接；
- 在手机浏览器中操作导致页面兼容异常；
- 链接生成后等待时间过长，提交时已经失效。

如果出现“订阅链接验证失败”，WildAI 建议重新登录 X，重新进入月付订阅页面并生成新的 Stripe 链接。必要时可以更换浏览器，或者暂时关闭代理和 VPN 后重试。

### 第四步：核对订单信息

链接验证通过后，页面通常会要求确认账户邮箱和订阅日期。这里填写或确认的邮箱应与 X 账号关联邮箱一致。

付款前重点检查：

- X 账号是否是自己的账号；
- 套餐名称是否正确；
- 是月付还是误选了年付；
- 订阅起止日期；
- 商品价格；
- 手续费；
- 最终合计金额；
- 是否存在自动续费或后续扣款说明。

WildAI 的教程说明，订单页面会显示订阅账户、有效期、价格、手续费和合计金额。不要只看商品价格，最后应以合计金额作为实际付款依据。

### 第五步：使用支付宝扫码付款

确认订单后进入收银台，选择支付宝或页面实际提供的支付方式完成付款。这里的支付页面属于 WildAI 订单流程，不是 X 的 Stripe 页面直接支持支付宝。

## 常见失败原因和处理方法

### 1. 把 X 页面链接当成 Stripe 链接

这是最常见的问题。WildAI 需要的是点击订阅后跳转到的完整 Stripe 结账地址，不是 X 的个人主页、Premium 介绍页或设置页。

处理方法很简单：重新进入 X Premium 订阅流程，点击月付订阅按钮，等 Stripe 页面出现后再复制地址栏完整内容。

### 2. 提交了年付链接

WildAI 当前公开说明只支持 X 月付订阅，不支持年付。即使 X 官方页面提供年付选项，也不要把年付链接提交到 WildAI。

如果你需要年付方案，应该先确认平台当前是否已经上线对应服务，不要根据官方页面的套餐选项自行推断第三方平台也支持。

### 3. 手机端生成链接失败

手机浏览器可能无法完整跳转或复制 Stripe 地址。WildAI 建议使用电脑端操作，尤其是生成链接、复制完整地址和提交订单这几个步骤。

### 4. 代理或 VPN 造成验证失败

Stripe 结账链接会受到网络环境、地区和链接状态影响。WildAI 帮助中心建议在验证失败时关闭代理或 VPN，重新生成链接；如果仍然失败，再更换浏览器或网络环境。

### 5. 支付成功但权益没有出现

先不要重新付款。依次检查：

1. WildAI 订单是否已经显示付款成功；
2. X 账号是否与生成链接时的账号一致；
3. X 订阅设置中是否已经更新；
4. 退出 X 后重新登录；
5. 保存订单截图和 X 订阅页面截图；
6. 联系 WildAI 客服核对订单。

如果初始订阅已经成功，但后续蓝色勾选消失或订阅被取消，WildAI 的帮助中心表示，这类情况需要同时查看 X 的账单记录，并优先联系 X 官方客服确认取消原因。WildAI 主要负责初次订阅代充，后续账号状态仍由 X 平台控制。

X 官方订阅属于周期性服务，订阅通常会按照所选付款方式自动续订，直到用户取消。通过第三方流程购买时，还要同时查看 WildAI 订单页面显示的有效期、续费方式和后续处理说明。

WildAI 的帮助中心说明，价格可能因为上游收单、服务状态或其他原因调整，最终应以付款前页面实时显示为准。网页搜索中出现的旧价格、优惠金额和别人订单截图，都不能替代当前收银台的实际金额。
